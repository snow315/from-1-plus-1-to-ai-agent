# `1 + 1 = 2` から AI Agent まで

[简体中文](../zh-CN/README.md) · [English](../en/README.md) · [ホーム](../../README.md)

## プロジェクトの目的

このプロジェクトでは、実行・観察・説明ができる小さな実験を積み重ね、計算の基礎から mini-LLM、AI Agent までを一つの連続した因果関係として理解します。

既存のフレームワークを呼び出すだけではなく、重要な仕組みごとに次の問いを扱います。

1. 入力はどのように表現されるか。
2. システムはどのような変換を行うか。
3. 何を観察できるか。
4. なぜその結果になるのか。
5. その仕組みは次の段階にどうつながるか。

## 学習の流れ

```text
基本メカニズム → ニューラルネットワーク → Transformer → LLM
→ 推論とランタイム → RAG / MCP → Agent → 最終 AI システム
```

## 実験の原則

- 一つの実験では一つの中心的な問いに答える。
- 実行前に結果を予測する。
- 仕組みが見える最小限の読みやすいコードを使う。
- 観察できる証拠に基づいて結論を出す。
- 現在の因果関係に必要な内容だけを扱う。

## 実行方法

各実験の `README.md` を読み、先に予測を書いてからコードを実行します。例：

```powershell
python .\LAB-0001\experiment.py
```

予測、実行結果、自分の説明を保存してください。コードが動いただけでなく、結果が生じた理由を説明できれば実験完了です。
