# Stage 01 — Foundations / 基础机制 / 基本メカニズム

[All labs](../README.md) · [Home](../../README.md)

This stage makes computation observable before introducing neural networks. It focuses on representation, rules, state changes, and how simple operations compose into larger computations.

本阶段在进入神经网络之前，先让计算过程变得可观察，重点理解表示、规则、状态变化，以及简单操作如何组合成复杂计算。

この段階ではニューラルネットワークに進む前に計算を観察可能にし、表現、規則、状態変化、単純な操作の組み合わせを理解します。
